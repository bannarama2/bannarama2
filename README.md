## 🚀 What I'm Working On

### 🎮 Tower Defense Upgrade System  
A Unity-based game with a **Tarkov-style inventory system** for placing and rotating upgrade pieces (like Tetris). Features include:
- Shape-based upgrades with synergy effects  
- Prefab-driven UI logic  
- Grid placement detection with rotation and inventory management  

### 🧠 Gamified ADHD Productivity App  
A task management app that uses **game mechanics** to motivate users. Think of a daily planner crossed with a leveling system. Key goals:
- Reinforce good habits through reward loops  
- Help users overcome executive dysfunction  
- Balance clean UI with a playful core  

### 🧬 Bare-metal Operating System  
An OS written from scratch in **C and Assembly**.  
Learning about:
- Bootloaders and low-level memory control  
- OS architecture design  
- Creating something that runs on the bare hardware
